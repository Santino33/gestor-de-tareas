Gestor de Tareas — Electiva PWA · UPTC

La aplicación actual usa TypeScript, Vite, IndexedDB, WebCrypto y Workbox.
La entrada es index.html -> src/main.ts. El Service Worker se genera en JavaScript.

Preparación: npm ci
Desarrollo: npm run dev
Producción/PWA: npm run build y luego npm run preview
Pruebas: npm test

Consulta README.md y docs/validacion-iteracion.md para requisitos, pruebas y resultados.

app.js, tareas.js y referencia-typescript/ conservan el material original de los
Bloques 1 y 2. No son el punto de entrada actual. Los archivos fuente TypeScript
requieren Vite; Live Server o python http.server sobre la raíz no los compilan.
